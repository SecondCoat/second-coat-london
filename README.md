# The Getaway Remaster

A new, free engine for **The Getaway** (PlayStation 2, 2002), by
[SecondCoat](https://secondcoat.dev). It plays the original from a disc image
of your own copy, at modern resolutions and frame rates, with mods and
multiplayer.

**Download and setup: [secondcoat.dev/the-getaway-remaster/download](https://secondcoat.dev/the-getaway-remaster/download/)**

This repository holds the [releases](https://github.com/SecondCoat/second-coat-london/releases):
each version's builds, the same files as on the download page. Each desktop
platform has two packages, the game alone and a full one (`-materials`) with
the large mods. The download page lists their SHA-256 checksums.

## You need your own copy

No data from the original game is included or distributed: no city, no
voices, no textures. The engine reads them from a disc image of your own
copy of The Getaway every time it runs.

## Bugs

Versions before 1.0 are test releases. Report bugs at
[bugs.secondcoat.dev](https://bugs.secondcoat.dev/the-getaway-remaster/).
